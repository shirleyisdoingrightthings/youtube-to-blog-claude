# 观察 / 观点类稿生成规范（第四种文体）

> 定位：把**多个一手信源**的重点与观察，**编织成一条属于我们自己的判断线**，做成一篇冷峻、严肃、经得起查的行业侧写。
> 与其他文体并列：图文精读（`illustrated_deepdive.md`）、对话体逐字稿（`dialogue_transcript.md`）、演讲实录。

---

## 一、这是什么，不是什么

- **是**：把多个一手信源（访谈、播客、研报、新闻，以及用户提供的数据 / 图表 / 截图）的重点，围绕**一条中心判断**编织、整合，输出一篇有观点、有分寸的行业观察。
- **不是**：单一视频 / 单一材料的转写或复述。**若用户只想还原某一个视频，走逐字稿（`dialogue_transcript.md`），不要走这里。** 单一转写不需要"判断线"，这里的核心恰恰是判断线。
- **与图文精读的区别**：图文精读重"按主题重构 + 可读性 + 发布全套要素"；观察类重"**一条判断线 + 多源佐证 + 克制的观点**"。

## 二、什么时候用它（路由）

- 手上有一个"引爆点"事件（某 CEO 发言 / 某笔交易 / 某个数据拐点）+ 若干可佐证的一手信源。
- 目标是"**给出一个行业判断**"，而不是"复述一个人说了什么"。

## 三、五条核心铁律（先记这个）

1. **先立判断线，再动笔。** 全篇只扛一个能被复述的中心判断；判断线没立住之前，不要往下写。
2. **编织，不是拼接。** 多源材料必须服务同一条判断线；每一段都要能回答"这条材料如何推进我的判断"。用不上的信源，砍掉，不硬塞。
3. **冷峻侧写，去情绪。** 少形容词、少煽情、不做个人抒情；以一个不动声色的分析师口吻梳理。观点靠"判断句"立，不靠情绪。
4. **主动去公关化。** 点破每个信源 / 主角屁股坐在哪，不替任何一方站台。
5. **经得起查。** 引语逐字、数字可核、含糊处加限定。

## 四、信源与素材（**不设死数量**）

- 信源数量**不限**——可能两三个，也可能七八个。关键不是数量，而是"**一手 + 可信 + 能相互印证或对撞**"。
- 类型：视频 / 播客的 Summary 或重点、访谈原话、研报、新闻，以及**用户提供的数据、图片、截图**。
- 处理顺序：先把每个信源提炼成"1–3 句可用的观察 / 事实"，再判断它落在判断线的哪一环；对撞的信源尤其宝贵（正反两方摆开，正是观点稿的可信来源）。

## 五、判断线（thesis）怎么立

- 一句话，能被读者转发时**原样引用**。（示例：本篇＝"企业 AI 的胜负，正从'最强模型'转向'谁掌控数据与工作流'"。）
- 配一个能**首尾咬合的比喻**（示例：卖水 vs 挖井 / 那口井），开头埋、结尾收。
- 判断线立完，先列出"要用哪几环观察去支撑它"，再开写。

## 六、结构模板：症状 → 证据 → 格局 → 落点

1. **引爆点（开头，非强制但推荐）**：用一个戏剧性事件切入（如 Karp 在 CNBC 情绪失控式的发言），但**立刻转入正题**，别停留在名场面本身。
2. **人话入口**：紧跟一个人人能对号入座的痛点问句 / 判断（如"花钱买 AI，养肥的却是对手？"）。
3. **立判断线**：把中心判断亮出来（可用小标题 + 首段完成）。
4. **多环观察（主体）**：每一环＝一个信源 / 一组事实 + 一张证据图 + 一句加粗判断，层层推进判断线。
5. **平衡 / 照镜子**：点破主角与各信源的利益立场（如"他是卖家""它自己也搞锁定"）。
6. **落点（结语）**：把判断线收成一句可引用的话，与开头的比喻咬合。

## 七、语调与用词

- **冷峻、严肃、克制的侧写**。像一个不动声色的分析师，而不是激动的评论员。
- 少破折号、少机械排比、少"这不是 X，而是 Y"的句式堆砌；避免"题眼 / 定海神针 / 斗兽场"这类煽情套话——**一篇最多留一两个招牌比喻**。
- **"观点感"来自判断句，不来自形容词。**

## 八、加粗规范

- 只给"判断句 / 落点句"加粗，每个 beat 至多一处。
- 加粗是给扫读读者标"重音"；滥用即失效。

## 九、图＝证据，不是插画

- 每一环观察尽量配一张能**佐证**的图：数据图表、成交额、架构图、信源截图。
- 正文或图注要点明这张图在证明什么，别当纯装饰。
- 复杂链路 / 流程可自制示意图（如技术栈闭环、分镜），并注明"情景演示，非真实案例"。

## 十、事实严谨铁律

- **引语**：真人原话逐字核到出处；核不到就降格为转述（去引号、写"大意是"）。外文专名 / 机构名 / 版本号先查证后定稿，拿不准显式标"建议人工核对"。
- **数字**：口径可疑的（某折算值、某百分比）标明来源或软化；**不要用"竟高达"陈述读者无法自证的数字**。
- **区分事实与信源观点**：凡属某信源的判断 / 爆料，署名"据 X"，不要写成客观事实。
- **主角的话要核事、也要核因果**：某方对"为什么发生 X"的叙述，常带自己的立场；有一手报道就以报道为准，并点破叙事与事实的落差。

## 十一、摘要 / 标题 / 封面

- **摘要**：≤ 20 字，扣中心判断或标题，用人话。
- **标题**：点名具体（人物 / 公司 / 事件）+ 利害清楚；动词有力，不写成流水账。
- **封面**：用**场景隐喻**表达中心判断，**不上主题词 / 大字**；一眼能读，缩略图也认得出（如"地下的数据井""牌桌上的庄家"）。

## 十二、定稿前自检清单

- [ ] 中心判断能一句话复述？开头 / 结尾用同一个比喻咬合了？
- [ ] 每一段都在推进这条判断线，没有跑题或硬塞的信源？
- [ ] 每个 beat 有一句加粗判断，尽量配一张证据图？
- [ ] 点破了各方利益立场，没替谁站台？
- [ ] 引语逐字、数字可核、含糊已加限定、信源观点已署名？
- [ ] 通篇冷峻克制，没有个人抒情 / 煽情、没有招牌比喻滥用？
- [ ] 摘要 ≤ 20 字、封面无大字、标题点名到位？

## 附：与其他文体的一句话区分

| 文体 | 一句话 | 何时用 |
|---|---|---|
| 逐字稿 | 还原一个访谈现场，标说话人 | 只想复刻某一个视频 |
| 图文精读 | 按主题重构一个视频，配齐公众号发布全套要素 | 深挖单一来源、要可读性与排版 |
| **观察 / 观点稿** | **多源一手素材，编织成一条自己的判断线** | **有引爆事件 + 多个信源，要给行业判断** |
